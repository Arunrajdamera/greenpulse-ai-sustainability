# Project description

Educational campuses need accessible ways to understand resource patterns and turn sustainability guidance into action. This prototype brings together simulated electricity, water, paper and waste data, explainable pattern analysis, a local sustainability knowledge base, source-aware assistant responses and practical recommendations.

It primarily supports SDG 12 by encouraging responsible resource consumption and waste reduction. It also connects energy efficiency to SDG 7, sustainable institutions to SDG 11 and climate-conscious behaviour to SDG 13. It is a student decision-support prototype, not a deployed campus monitoring system.
