# Responsible AI & data transparency

- **Transparency:** UI and API label simulated data and Demo AI Mode.
- **Explainability:** Each alert includes observed and baseline averages plus a human-readable reason.
- **Grounding:** Chat responses list relevant local knowledge-source filenames.
- **Privacy:** No personal information is collected or modelled.
- **Human oversight:** Recommendations are suggestions pending appropriate human review.
- **Limitations:** Simulated data does not represent actual institutional consumption. Retrieval can miss relevant wording and it does not replace technical inspection or facilities expertise.

AI-generated recommendations are intended for decision support and should be reviewed by an appropriate human before implementation.
